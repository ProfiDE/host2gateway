# Contributing to host2gateway

Thanks for your interest! 🎉

## Quick Start

1. **Open an issue** – Describe what you want to work on (optional but recommended)
2. **Fork the repo** on GitHub
3. **Clone your fork**:
   ```bash
   git clone https://github.com/[your-username]/host2gateway.git
   cd host2gateway
   ```
4. **Create a branch**:
   ```bash
   git checkout -b your-feature-name
   ```
5. **Make your changes**
6. **Commit** (see rules below)
7. **Push and open a Pull Request**

---

## Commit Message Rules

This project follows [Conventional Commits](https://gist.github.com/qoomon/5dfcdf8eec66a051ecd85625518cfd13) for writing clear, machine-readable commit messages.

Each commit message must be structured as follows:

```
<type>(<scope>): <subject>
```

**Examples:**
```bash
feat(server): add 4096-bit RSA key generation
fix(client): resolve permission error
docs: update README
refactor(host): move config to separate file
```

---

## Pull Request Guidelines

- PRs should target the `master` branch
- Describe what you changed and why
- One PR = one focus (not multiple unrelated changes)

---

## Reporting Issues

> Please open an issue first before starting work. This helps us discuss the problem and avoid duplicate efforts.

Include:
- What happened?
- Steps to reproduce
- Your environment (OS, PHP version)
